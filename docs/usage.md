# 使用说明

## 环境与启动

本机已在 `.venv` 中安装依赖，可双击 `run.bat`，或运行 `run.ps1`。启动入口是 `python -m algoviz`，必须使用项目虚拟环境的解释器。

依赖固定为 PySide6 6.8.3、OpenCV Headless 4.11.0.86、NumPy 1.26.4、psutil 7.0.0；pytest 用于测试。OpenCV 负责图形几何和颜色，Qt 负责窗口与中文文字。

已找到的 `D:\Fake_U\opencv` 原安装保持不变。其 Python 3.9 绑定在此机器加载时缺少 DLL，因此本项目使用虚拟环境内的兼容 OpenCV。无需将两套 OpenCV 混入同一 Python 环境。

编译器和调试器优先使用 `C:\mingw64\bin\g++.exe` 与 `gdb.exe`。需要更改时，在启动终端设置：

```powershell
$env:ALGOVIZ_CXX = 'C:\your-mingw\bin\g++.exe'
$env:ALGOVIZ_GDB = 'C:\your-mingw\bin\gdb.exe'
.\run.ps1
```

请使用同一套 MinGW GCC / GDB，GDB 需支持 Python。程序自动加载该 GCC 目录下的 libstdc++ pretty-printer；MSVC/Clang、WSL 和多文件工程不在首版支持范围内。

安装时如果 Anaconda 提示 SSL DLL 缺失，`setup.ps1` 会为本次进程补充其 `Library/bin` 路径，不修改系统 PATH。若直接执行 PowerShell 脚本受限制，可使用 README 中只对该进程生效的启动命令。

## 代码和断点

- **完整程序**：输入包含 `main` 的单文件 C++17 程序，可定义其他函数。
- **语句片段**：输入函数体内的语句，自动补齐 `bits/stdc++.h`、`using namespace std`、`main` 和末尾返回；独立函数定义应使用完整程序模式。
- “输入代码”保留原文，“实际编译源码”显示实际编译文件。片段原文第 1 行对应编译源码第 5 行。
- 调试期间输入代码锁定；在实际编译源码行号左侧点击设置或移除断点。调试前也可在输入代码中设置断点。
- 修改输入代码会清除其断点，避免原行号错误地指向另一条语句。调试期间修改的用户代码断点会同步到输入代码，重启时保留。
- GDB 可能将空行等不可执行位置的断点移动到最近的可执行行。暂停时高亮的是 GDB 报告的实际位置。
- 打开与保存使用 UTF-8 `.cpp`；保存的是输入原文。每次编译的实际源码保存在 `.runs/session-*/program.cpp`。

## 调试按钮

| 操作 | 行为 |
| --- | --- |
| 开始 / F5 | 编译并暂停在 main；暂停中 F5 为继续 |
| 逐过程 / F10 | 执行下一源码行，通常不进入函数 |
| 进入 / F11 | 进入调用，可能进入标准库 |
| 跳出 / Shift+F11 | 执行至当前函数返回 |
| 继续 | 运行至断点、异常或退出 |
| 自动单步 | 按设定间隔重复逐过程；断点和异常会停止播放 |
| 暂停播放 | 当前单步完成后停止自动播放 |
| 停止 | 终止当前编译 / 调试进程及其子进程 |
| 重启 | 终止旧进程，重新编译，清空旧历史和分页 |

高亮行**还没有执行**；变量是暂停时的真实值。若同一行有多个表达式，GDB 不保证分别暂停。请将需要观察的修改写在独立行上。

“暂停播放”不强行中断正在执行的一条语句；死循环、阻塞调用可用“停止”结束。进入标准库时，用户源码不显示误导性的行高亮；调用栈显示当前位置，可“跳出”返回。

## 图形与变量

当前栈帧可见的局部变量和参数自动出现。整型、浮点、布尔、字符和字符串使用卡片；数组 / 矩阵从右上角下拉框选择。下方变量表提供完整类型与状态，较长内容可悬停查看。

- 一维原生数组、`std::array`、`std::vector`（包括 `vector<bool>`）显示下标和值，可切换柱状图。负数柱体显示在零线下方。
- 原生二维数组和二维 `vector` 显示矩阵网格。每个单元格显示行列索引，颜色根据**当前页**数值范围计算。
- 每个容器一次读取最多 200 个叶子元素，上一页 / 下一页只在最新暂停状态可用。矩阵分页展示本页涉及的行列；以单元格索引为准。
- 在右侧选择索引变量，再选择“数组下标 / 矩阵行 / 矩阵列”并绑定。可以绑定多个变量；越界会提示，不据此读取越界元素。
- 橙色边框表示与上一快照相比值发生变化，青色表示索引指向位置。比较只覆盖两次快照中都已读取的单元格。
- 添加全局观察项使用变量名或限定名，如 `::total`、`example::count`。首版不接受任意函数调用、赋值或复杂表达式。输入相同名称后可移除观察。
- 作用域和栈帧用于区分同名变量；同一作用域只显示当前可见的名称。不可见、不可读或不支持的值给出状态或摘要。

请显式初始化变量。C++ 调试信息无法可靠标记全部未初始化值，因此界面始终提示这项限制；看到数值不代表该变量已经合法初始化。不等长二维容器不作为普通矩阵解释；检测到的不等长行会标记，请使用矩形矩阵。原始指针只显示地址 / 摘要，不自动沿指针访问内存。

## 历史与导出

内存中保留最近 500 次执行快照。拖动底部时间条查看历史，标签明确标记“历史回看”。这不会倒退执行程序。下一次执行会先回到最新快照。

翻页、修改观察项和断点仅刷新最新快照，不增加历史条目。历史中只有当时已读取的页面，没有采集的数据不能回溯补齐。索引绑定是当前展示配置，回看时使用历史变量值。

“导出 PNG”保存当前图形原始分辨率，包含变量名、下标和标注；界面缩放不影响导出。大图可使用滚动条或切换 100% 查看。

## 标准输入、输出与文件

在运行前填写“标准输入”。程序通过文件重定向提供给 `cin` / `scanf`，不是交互终端；内容用尽后读取到 EOF。运行后输出独立显示，每 500 ms 刷新一次；C/C++ 自身缓冲可能延迟显示，可使用 `endl`、`flush` 或 `fflush`。

每次运行使用独立的 `.runs/session-*` 目录，含源码、可执行程序、输入和两个输出文件。界面最多展示 stdout / stderr 各末尾 100 KB，完整输出保留在该目录。此目录不纳入 Git，可在关闭程序后自行清理。

停止、重启或关闭窗口会终止该会话的编译器 / GDB 及其子进程，不终止其他项目的进程。工具在本机运行用户代码，不提供执行沙箱，应只运行可信代码。

## 推荐体验

1. **冒泡排序**：绑定 `a ← i` 和 `a ← j`，在 `a[j] = a[j + 1]` 设置断点，单步观察交换。
2. **二分查找**：绑定 `a ← left/right/mid`，观察指针移动；`right = -1` 等结束状态会显示越界提示。
3. **二维动态规划**：选择 `dp`，绑定 `row` 为行、`col` 为列，观察单元格更新。
4. **递归**：在 `factorial(n)` 调用处进入，查看参数、局部变量和调用栈，然后跳出。

首版不包含树 / 图语义推断、多文件构建、真正反向执行、交互终端或安装包。当前验证工具链为 Windows 上的 MinGW GCC 14.2.0 / GDB 16.2。
